# NOIR CINEMA — public node

English-first public surface. Arabic is a switch, not the default.

## Live
- Code: https://github.com/4skylr/noir-cinema
- Preview: https://raw.githack.com/4skylr/noir-cinema/main/index.html
- Pages (after enable): https://4skylr.github.io/noir-cinema/

## Theme
Brutalist Web3 cinema. Film sprockets, acid signal, projector dust, append-only ledger language. Brand violet `#7A2A90` kept as the chain color, not the whole UI.
